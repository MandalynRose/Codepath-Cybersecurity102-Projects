# Project 7: Real-World Threat Hunting

## Overview
In the Unit 7 project, you'll act as a SOC analyst at PathCode Inc. and conduct two real-world threat hunting investigations using the same correlation technique from the lab. 
You'll hunt for evidence of two separate attacks in PathCode's network logs, investigate matched indicators on VirusTotal, and write a short analysis comparing what you found.

## Tools Used
- Splunk
- Docker
- VirusTotal
- Threat Intelligence IOC Lists (CSV Files)

## What I learned
- Learned how to identify indicators of compromise (IOCs).
- Used Splunk to find suspicious IP addresses and domains.
- Compared threat intelligence lists with network logs.
- Identified affected computers and suspicious activity.
- Learned how cyber threats can change over time.
