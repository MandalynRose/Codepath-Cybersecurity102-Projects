# Project 6: CSIRT: PathCode

## Overview
You're the relay analyst on PathCode's CSIRT. A first responder — Sam Johnson — triaged a malware incident and filed an initial report, but the analysis and recommendations are still pending. Pick up where she left off: document the incident in Catalyst, research the indicators, audit her report for gaps, and write the analysis that turns a first-responder's notes into a real post-incident record.

## Tools Used
- Docker: Runs applications in isolated environments.
- Catalyst: Creates, tracks, and documents security incidents.
- VirusTotal: Analyzes files, hashes, URLs, and IP addresses for malicious activity.
- AbuseIPDB: Checks whether IP addresses have been reported for malicious activity.

## What I learned
- Created and documented a cybersecurity incident in Catalyst.
- Researched Indicators of Compromise (IOCs) using VirusTotal and AbuseIPDB.
- Classified an incident based on severity and TLP.
- Identified missing information and detection gaps in an incident report.
- Recommended security controls using defense-in-depth.
- Learned how to write an effective Lessons Learned analysis to help prevent future incidents.
